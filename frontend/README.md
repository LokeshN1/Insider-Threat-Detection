# Anomaly Detection Frontend

This repository contains the frontend interface for the Anomaly Detection application, designed to provide users with an intuitive way to input data and receive anomaly predictions.

## Features

- **User Input Options**: Users can choose to input data via:
  - A user-friendly form for inserting entries one by one
  - JSON format for inserting all features in once

- **Dynamic Results Display**: Prediction results are displayed only after user submission, showing whether the input is classified as "Normal" or "Anomaly".

- **Responsive Design**: The application is designed to be responsive and visually appealing, enhancing the user experience.
